# README banner

The 1200 × 128 banner uses the landing page CTA's white background, orange accent, Newsreader lettering, and repeated ornament. The SVG is self-contained, with lettering outlined and the existing ornament embedded. The PNG is the README display asset, rendered at 2× resolution.
